Conectar WhatsApp Business

Conectá tu número para enviar y recibir mensajes desde el panel. Los datos se guardan temporalmente en Redis (Memurai).

Embedded Signup de Meta (recomendado para Technology Provider).

Configuración en Meta (una sola vez):
  • App → Facebook Login for Business → Valid OAuth Redirect URIs: agregá la URL de esta página (ej. /connect)
  • App → Settings → Basic → Allowed Domains for the JavaScript SDK: tu dominio (localhost o ngrok)
  • App → WhatsApp → Embedded Signup → copiá el Configuration ID a WHATSAPP_CONFIGURATION_ID en .env

Pegá los datos desde Meta → WhatsApp → API Setup (útil para desarrollo).
